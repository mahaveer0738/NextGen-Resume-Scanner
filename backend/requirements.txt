#  requirements.txt  —  All Python packages needed

#  📌 WHAT IS requirements.txt?
#     This file lists every Python library this project needs.
#     Install them ALL at once:  pip install -r requirements.txt
#
#  📌 WHY NO STRICT VERSIONS HERE?
#     AI libraries (LangChain, LangGraph, Gemini) release
#     updates very frequently. Strict versions like ==2.7.1
#     cause conflicts. We use >= so pip picks the latest
#     compatible set automatically.
# ============================================================
